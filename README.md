# Daftar Tugas Kuliah

Aplikasi web pengelolaan daftar tugas perkuliahan yang dibuat menggunakan **Vite** dan **TypeScript** (Vanilla).

## Fitur Utama
- Menampilkan daftar tugas kuliah beserta progres dan statistik penyelesaian.
- Menambahkan tugas baru (judul tugas, mata kuliah, tenggat waktu).
- Mengedit dan menghapus tugas.
- Mengubah status tugas (`Belum Selesai` / `Selesai`) beserta filter tampilan.
- Menyimpan data secara persisten menggunakan `localStorage`.
- Konfigurasi nama dan versi aplikasi menggunakan Environment Variables (`.env`).

## Cara Menjalankan Proyek

```bash
# 1. Instal dependensi
npm install

# 2. Jalankan server development
npm run dev

# 3. Build untuk produksi
npm run build
```
